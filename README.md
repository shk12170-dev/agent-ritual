# T09 — 리추얼에서 강점과 자기소개서의 뼈대 찾기

한 달간(8/12~9/11)의 아침·마무리 리추얼 기록에서 반복적으로 나타나는 행동을 근거로
강점 지도를 뽑고, 시작·고비·지금 구조의 1인칭 이야기와 자기소개서 초안, 포트폴리오
뼈대를 정리한 결과물입니다. 이야기는 동료 두 명에게 "나 같은가?", "지어낸 느낌이
있는가?"를 물어 검증받았습니다.

## 구성

- `index.html` — 배포용 요약 페이지 (자기소개서 · 강점 지도 · 이야기 · 동료 피드백 · 포트폴리오 뼈대)
- `과제9_강점과자기소개서.md` — 전체 작업 과정과 근거(리추얼 기록 인용, 동료 피드백 전문)
- `과제9_동료공유용_이야기.md` — 동료 검증에 실제로 사용한 요청 메시지 + 이야기 + 답변
- `과제9_체크리스트.md` — 작업 단계별 진행 체크리스트
